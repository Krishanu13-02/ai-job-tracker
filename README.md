# AI Job Tracker

A full-stack, AI-powered job tracking app that helps developers discover relevant roles, upload resumes, and filter jobs using natural language with OpenAI.

## 🔥 Features
- Live job search & listing (external jobs API)
- Resume upload (PDF/TXT)
- AI-powered job filtering using OpenAI (e.g., “show React jobs”)
- Job match scoring
- Application tracking
- Deployed frontend + backend

## 🧱 Tech Stack
- Frontend: React + Vite (Vercel)
- Backend: Node.js (Render)
- AI: OpenAI API
- APIs: REST (Jobs API)
- Deployment: Vercel (frontend), Render (backend)
